# pstack

The pstack skill set: principles, verification, and workflow skills.

These are pstack skills, vendored from the gizmo repo's `skills-ref/pstack` copy. No upstream URL is
named in the skill sources, so none is cited here.

Only the skills are shipped: every skill directory lives under `skills/`, with its own
`references/`, `playbooks/`, and `scripts/` folders intact.
